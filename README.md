# CryptoLens

Enterprise Cryptographic Discovery & Analysis Tool (ECDAT). 

A platform for tracking cryptographic assets, managing vulnerabilities, and planning migrations to Post-Quantum Cryptography (PQC).

## Features

- **Dashboard:** Executive summary of cryptographic posture and Mosca risk scores.
- **CBOM Inventory:** Cryptographic Bill of Materials showing algorithms, keys, and network boundaries.
- **Asset Graph:** Multi-node dependency graph from source repositories to live endpoints.
- **Migration Planner:** Automated remediation paths for PQC transition.

## Getting Started

First, run the development server:

```bash
pnpm dev
# or
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.
